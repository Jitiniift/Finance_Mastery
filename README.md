## 📌 What Is This?

This repository is a **complete, end-to-end finance career portfolio** built around a single fictional company — **Clearline Supply Co.** ($2.4M US-based B2B distributor). Every model, every template, every report uses the **same dataset** from Phase 1 through Phase 7.

It's not a collection of random files. It's a **connected business story** — from the first journal entry to the final DCF valuation.

```
💡 Every file here has a companion YouTube video explaining the concept, the build, and the business logic.
📺 Channel: youtube.com/@fpnajitin
```

| **Structure** | Multi-entity (US parent + Canadian subsidiary) |
| **ERP** | QuickBooks Online (accrual basis) |
| **Integrations** | Bill.com · Shopify · Avalara · Dext · Gusto |

> This business is designed to be complex enough to teach real-world finance — but simple enough that a commerce student can follow from Day 1.

```

└──────────────┘      └──────────────┘      └──────────────┘     └──────────────┘
                                                   │
                                                   ▼
Phase 8               Phase 7                Phase 6
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│  AI +        │      │  DCF + M&A   │      │  Strategy    │
│  Automation  │ ◄─── │  Valuation   │ ◄─── │  Frameworks  │
│  + Markets   │      │  + Deal Model│      │  + Linkage   │
```

> **The DCF in Phase 7 uses the P&L built in Phase 3 — same numbers. The BCG Matrix in Phase 6 uses segment data from the same QBO company file. Nothing is disconnected.**
